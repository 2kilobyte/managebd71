## Discord setup invites

When Discord setup cannot find a registered player in the configured server, the bot sends that player a DM with the tournament and team names plus a server invite button. To use a fixed invite link, add it to the Admin app's local `.env.local` file:

```env
DISCORD_SERVER_INVITE_URL=https://discord.gg/your-invite-code
```

If no invite URL is configured, the bot tries the server's system channel and then another public text channel where it can create a seven-day invite (the bot needs Create Instant Invite permission there). A blocked DM or unavailable invite is recorded in the tournament's Discord setup history and does not stop setup.
